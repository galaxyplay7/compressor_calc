# Kebijakan Privasi

**Starting Air Compressor Calculator**
Terakhir diperbarui: 14 November 2026

Terima kasih sudah memakai Starting Air Compressor Calculator. Dokumen ini menjelaskan bagaimana halaman ini menangani data kamu.

## 1. Ringkasan

Kami tidak mengumpulkan, menyimpan, atau membagikan data pribadi kamu. Semua perhitungan dilakukan langsung di browser perangkat kamu.

## 2. Data yang kamu masukkan

Angka yang kamu isi di kalkulator (`Vst`, `neng`, `nst`, dan `T`) hanya diproses di browser untuk menampilkan hasil. Data ini:

- tidak dikirim ke server mana pun,
- tidak disimpan di database,
- tidak disimpan di cookie atau penyimpanan lokal browser,
- hilang saat halaman ditutup atau di-refresh.

## 3. Cookie dan pelacakan

Halaman ini tidak memakai cookie, tidak memasang alat analitik, dan tidak melakukan pelacakan perilaku pengguna.

## 4. Layanan pihak ketiga

Supaya tampilan berjalan, halaman ini memuat sumber daya dari layanan pihak ketiga:

- **Tailwind CSS** (`cdn.tailwindcss.com`) untuk gaya tampilan
- **Google Fonts** (`fonts.googleapis.com`) untuk font Inter

Saat halaman dibuka, browser kamu mengirim permintaan ke layanan tersebut, sehingga mereka dapat menerima informasi teknis standar seperti alamat IP dan jenis browser. Hal ini di luar kendali kami. Penanganan data oleh mereka diatur oleh kebijakan privasi masing-masing penyedia.

## 5. Fitur Salin Hasil

Tombol **Salin Hasil** hanya menyalin teks hasil perhitungan ke clipboard perangkat kamu atas perintah kamu sendiri. Isi clipboard tidak dibaca atau dikirim ke mana pun.

## 6. Hosting

Jika halaman ini diakses lewat GitHub Pages, GitHub sebagai penyedia hosting dapat mencatat data akses standar (misalnya alamat IP) sesuai kebijakan privasi GitHub.

## 7. Anak-anak

Halaman ini tidak ditujukan khusus untuk anak-anak dan tidak mengumpulkan data pribadi dari siapa pun, termasuk anak di bawah umur.

## 8. Perubahan kebijakan

Kebijakan ini bisa diperbarui sewaktu-waktu. Perubahan akan dicatat di repositori ini, dan tanggal "Terakhir diperbarui" di atas akan menyesuaikan.

## 9. Kontak
